This readme file contains information on SUVA data supplied as supporting information for the paper by Fox et al., 2018. Please see that manuscript for details on field site and methods.

SUVA (specific UV absorbance) data is supplied in one file: "SUVA data_NaCl whole_PP-SPE.csv" contains data for organic matter extracted (0.01 M NaCl or 0.1 M sodium pyrophosphate) from sediments. Pyrophosphate extracts (PP) are purified through solid-phase extraction (SPE). 

All data was collected using a Thermo Aquamate Plus UV-Vis spectrophotometer using a 1-cm quartz cell. NaCl whole samples were run un-diluted, while PP-SPE samples were diluted 40x with MilliQ water. The baseline was zeroed on a MilliQ water blank prior to collecting sample spectra. All data was corrected for dilution, converted to m-1 by multiplying by 100, and divided by the DOC concentration in mg/L to convert the raw absorbance values to specific absorbance in units of L/mg-m. 

See 'summary of sediment data_Fox et al 2018.xlsx' file to identify individual sample names (depths, GPS locations).
