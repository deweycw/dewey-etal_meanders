This readme file contains information on C NEXAFS and STXM data supplied as supporting information for the paper by Fox et al., 2019. Please see that manuscript for details on field site and methods or contact Patricia Fox at Lawrence Berkeley National Laboratory (pmfox@lbl.gov).

Data is supplied in two files:

C_NEXAFS data_shale.csv contains bulk carbon NEXAFS data for shale samples collected from PLM6 (weathered and unweathered) and GRO (top, middle, bottom).

C_STXM data_sediment.csv contains C STXM data for floodplain sediment samples collected from the cut-bank (MC-1) and middle (MC-3) of meander C. Data was collected at several spots (or particles) for each sample. The cores were collected at the location of the MCT2 transect wells. 

Both normalized data and data fits are presented.
