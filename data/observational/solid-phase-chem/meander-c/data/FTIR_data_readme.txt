This readme file contains information on FTIR data supplied as supporting information for the paper by Fox et al., 2019. Please see that manuscript for details on field site and methods or contact Patricia Fox at Lawrence Berkeley National Laboratory (pmfox@lbl.gov).

FTIR data is supplied in two files:

FTIR data_FLF_OLF.csv contains data for organic fractions from density separations (FLF=free light fraction, OLF=occluded light fraction).

FTIR data _HCl-SPE_PP-SPE_PP-1kD.csv contains data for organic matter extracted (by 0.5 M HCl or 0.1 M sodium pyrophosphate) from sediments and purified through solid-phase extraction (SPE) or dialysis (1kD). 

All data was collected by ATR-FTIR (Thermo Scientific Nicolet iS50) equipped with a quartz crystal. All data was collected with a liquid nitrogen cooled MCT/A detector. Atmospheric suppression, ATR-correction, baseline correction, and intensity normalization were performed on background-corrected sample spectra using OMNIC software. The corrected and normalized spectra are given here.

See 'summary of sediment data_Fox et al 2018.xlsx' file to identify individual sample names (depths, GPS locations).
